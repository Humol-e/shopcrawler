# ShopCrawler

A web crawler for discovering product URLs on e-commerce websites. Built with Express and Puppeteer, deployed on Netlify with serverless functions.

## Features
- Headless browser automation using Puppeteer
- Screenshot capture of webpages
- Serverless deployment via Netlify
- Easy-to-use API endpoint for testing
